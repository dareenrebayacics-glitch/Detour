**Detour**

Detour is a Python-based route and itinerary planning application designed for boutique hotels, resorts, and tourists. It helps users create customized travel routes while supporting driving, walking, and cycling transportation modes.

The application uses the MapQuest API to generate routes and allows users to dynamically add or remove scenic, cultural, tourism, and rest-stop destinations from their itinerary
This project enhances the existing Lab 4.9.2 route-planning application by adding itinerary management while applying social coding practices through GitHub branches, commits, pull requests, code reviews, and collaborative development.

**Key Features**
Route generation for driving, walking, and cycling
Dynamic addition and removal of destinations
Customized tourism and scenic itineraries
MapQuest API integration for route planning
Input validation and error handling
GitHub-based collaborative development

**Project Objectives**
Improve the existing route-planning application with practical tourism features.
Allow users to customize their travel itineraries based on preferred destinations.
Provide route to support better trip planning.
Demonstrate effective social coding practices and collaborative software development.

**Technologies Used**
Python
MapQuest REST API
GitHub / Git
REST API Integration
